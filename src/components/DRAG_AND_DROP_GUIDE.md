# 表單設計器拖曳功能使用指南

## 概述

表單設計器現在支援完整的拖曳功能，讓您可以：
1. 在群組內調整欄位順序
2. 將欄位拖曳到不同的群組
3. 使用上下按鈕快速調整順序

## 功能說明

### 1. 拖曳移動欄位

#### 在群組內移動
- 點擊並拖曳欄位左側的拖曳圖示（☰）
- 拖曳到目標位置
- 放開滑鼠完成移動

#### 跨群組移動
- 點擊並拖曳欄位
- 拖曳到目標群組的任意位置
- 放開滑鼠完成移動
- 欄位會自動更新群組設定

### 2. 上下按鈕調整順序

- 點擊欄位左側的上/下箭頭按鈕
- 欄位會在當前群組內移動
- 適合微調順序

### 3. 視覺提示

- **拖曳中**：被拖曳的欄位會變半透明
- **放置目標**：目標位置會顯示藍色分隔線和「放置在此處」提示
- **目標群組**：目標群組的卡片會顯示藍色邊框

## 使用步驟

### 步驟 1：在群組內調整順序

1. 找到要移動的欄位
2. 點擊並拖曳欄位左側的拖曳圖示（☰）
3. 拖曳到目標位置（會顯示藍色分隔線）
4. 放開滑鼠

**或使用上下按鈕：**
1. 點擊欄位左側的上/下箭頭
2. 欄位會立即移動

### 步驟 2：將欄位移到其他群組

1. 點擊並拖曳欄位
2. 拖曳到目標群組的任意位置
3. 觀察目標群組的視覺提示（藍色邊框）
4. 放開滑鼠
5. 欄位會自動更新群組設定

### 步驟 3：將欄位移到未分組

1. 點擊並拖曳欄位
2. 拖曳到「未分組欄位」區域
3. 放開滑鼠
4. 欄位的群組設定會被清空

## 操作技巧

### 技巧 1：精確定位

- 拖曳時會顯示藍色分隔線，表示放置位置
- 可以拖曳到欄位之間或群組的開頭/結尾

### 技巧 2：快速調整

- 對於小幅調整，使用上下按鈕更快速
- 對於大幅移動或跨群組移動，使用拖曳更方便

### 技巧 3：批量移動

- 可以連續拖曳多個欄位
- 每次移動後順序會自動更新

## 範例場景

### 場景 1：調整「基本資訊」群組的欄位順序

**目標**：將「中文名稱」移到「英文名稱」之前

**方法 1（拖曳）：**
1. 拖曳「中文名稱」欄位
2. 拖曳到「英文名稱」上方
3. 放開滑鼠

**方法 2（按鈕）：**
1. 如果「中文名稱」在「英文名稱」下方
2. 點擊「中文名稱」的上箭頭按鈕
3. 重複直到順序正確

### 場景 2：將欄位移到不同群組

**目標**：將「供應商」從「物料資訊」移到「訂購資訊」

**步驟：**
1. 拖曳「供應商」欄位
2. 拖曳到「訂購資訊」群組
3. 選擇放置位置（例如：放在「最小訂購量」之後）
4. 放開滑鼠
5. 「供應商」欄位的群組會自動更新為「訂購資訊」

### 場景 3：建立新群組並移動欄位

**目標**：建立「成本資訊」群組，並將相關欄位移過去

**步驟：**
1. 點擊「管理群組」按鈕
2. 新增群組「成本資訊」
3. 拖曳「單價」欄位到「成本資訊」群組
4. 拖曳「成本」欄位到「成本資訊」群組
5. 拖曳「幣別」欄位到「成本資訊」群組

## 注意事項

1. **拖曳限制**：
   - 不能拖曳到欄位編輯對話框內
   - 拖曳時避免點擊其他按鈕

2. **順序更新**：
   - 移動欄位後，`display_order` 會自動更新
   - 不需要手動調整順序數字

3. **群組更新**：
   - 跨群組移動時，欄位的 `field_group` 會自動更新
   - 不需要手動編輯欄位來修改群組

4. **視覺反饋**：
   - 拖曳時注意藍色提示線
   - 目標群組會有藍色邊框提示

## 故障排除

### 問題 1：無法拖曳欄位

**可能原因：**
- 瀏覽器不支援 HTML5 拖曳 API
- 欄位正在編輯中

**解決方法：**
- 使用現代瀏覽器（Chrome, Firefox, Safari, Edge）
- 關閉欄位編輯對話框後再試

### 問題 2：拖曳後欄位位置不正確

**可能原因：**
- 拖曳邏輯計算錯誤
- 群組名稱不一致

**解決方法：**
- 重新載入表單
- 檢查欄位的群組設定是否正確

### 問題 3：無法跨群組移動

**可能原因：**
- 目標群組不存在
- 拖曳事件被阻止

**解決方法：**
- 確認目標群組已建立
- 嘗試重新拖曳

## 鍵盤快捷鍵（未來擴展）

目前不支援鍵盤快捷鍵，但可以考慮未來新增：
- `Ctrl + ↑`：上移欄位
- `Ctrl + ↓`：下移欄位
- `Ctrl + Shift + ↑`：移到群組開頭
- `Ctrl + Shift + ↓`：移到群組結尾

## 相關功能

- **群組管理**：使用「管理群組」按鈕管理群組
- **欄位編輯**：點擊編輯按鈕修改欄位屬性
- **預覽功能**：切換到「預覽」標籤查看效果
