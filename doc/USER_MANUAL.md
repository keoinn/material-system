## 系統簡介

物料編碼申請管理系統 V3.6 是一個用於管理物料編碼申請、審核、查詢和匯出的完整管理系統。系統支援動態表單設計、多層級審核流程、角色權限管理等功能。

### 主要特色

- ✅ **動態表單系統**：可自訂義表單結構，無需修改程式碼
- ✅ **多層級審核流程**：支援多層級審核與審核意見記錄
- ✅ **角色權限管理**：細緻的權限控制，確保資料安全
- ✅ **Excel 匯出功能**：支援多條件篩選與資料匯出
- ✅ **選項活頁簿**：集中管理表單選項資料
- ✅ **響應式設計**：支援桌面、平板、手機等多種裝置

## 功能模組說明

### 1. 物料申請

**功能說明**：用於提交物料編碼申請表單。

**使用步驟**：

1. 從首頁點擊「物料申請」卡片，或從側邊欄選擇「物料申請」
2. 系統會載入動態表單（表單結構由系統管理員設定）
3. 填寫表單各欄位：
   - **必填欄位**：標示有紅色星號（*）的欄位必須填寫
   - **選填欄位**：可選擇性填寫
   - **下拉選單**：點擊下拉箭頭選擇選項
   - **複選框**：可選擇多個選項
   - **日期欄位**：點擊日期選擇器選擇日期
   - **檔案上傳**：點擊「選擇檔案」按鈕上傳附件
4. 填寫完成後，點擊「提交」按鈕
5. 系統會自動產生料號（如果表單有設定自動產生料號功能）
6. 提交成功後，申請會進入審核流程

**注意事項**：

- 表單會自動儲存草稿，未完成的表單可以稍後繼續填寫
- 提交前請確認所有必填欄位都已填寫
- 如果表單有設定驗證規則，系統會自動檢查資料格式

**欄位類型說明**：

- **文字欄位**：直接輸入文字
- **多行文字**：可輸入多行文字內容
- **數字欄位**：只能輸入數字
- **下拉選單**：從預設選項中選擇一個
- **多選下拉**：可選擇多個選項
- **複選框**：可選擇多個選項（每個選項會顯示為獨立列）
- **單選框**：只能選擇一個選項
- **日期**：選擇日期
- **日期時間**：選擇日期和時間
- **檔案上傳**：上傳檔案附件
- **JSON 資料**：輸入 JSON 格式的資料

### 2. 申請查詢

**功能說明**：查詢已提交的申請記錄。

**使用步驟**：

1. 從首頁點擊「申請查詢」卡片，或從側邊欄選擇「申請查詢」
2. 設定查詢條件：
   - **表單**：選擇要查詢的表單類型
   - **開始日期**：設定查詢的起始日期
   - **結束日期**：設定查詢的結束日期
   - **狀態**：選擇要查詢的申請狀態（全部、待審核、已核准、已退回等）
3. 點擊「查詢」按鈕
4. 系統會顯示符合條件的申請記錄列表
5. 點擊記錄可查看詳細資訊

**查詢結果說明**：

- **記錄ID**：申請記錄的唯一識別碼
- **料號**：自動產生的物料編號
- **狀態**：申請的當前狀態（以不同顏色的標籤顯示）
- **申請人**：提交申請的使用者
- **提交日期**：申請提交的時間
- **其他欄位**：根據表單設定顯示的欄位

**操作功能**：

- **查看詳情**：點擊記錄可查看完整的申請資料
- **匯出**：可將查詢結果匯出為 Excel 檔案

### 3. EXCEL匯出

**功能說明**：將申請資料匯出為 Excel 檔案（CSV 格式）。

**使用步驟**：

1. 從首頁點擊「EXCEL匯出」卡片，或從側邊欄選擇「EXCEL匯出」
2. 設定匯出條件：
   - **表單**：選擇要匯出的表單類型
   - **開始日期**：設定匯出的起始日期
   - **結束日期**：設定匯出的結束日期
   - **狀態**：選擇要匯出的申請狀態
3. 點擊「預覽資料」按鈕查看符合條件的資料
4. 確認資料無誤後，點擊「匯出EXCEL」按鈕
5. 系統會下載 CSV 格式的檔案

**匯出資料說明**：

- **單號**：申請記錄的唯一識別碼
- **料號**：自動產生的物料編號
- **狀態**：申請的當前狀態
- **申請人**：提交申請的使用者
- **提交日期**：申請提交的時間
- **核准日期**：申請核准的時間（如果已核准）
- **退回日期**：申請退回的時間（如果已退回）
- **退回原因**：退回的原因說明（如果有）
- **表單欄位**：根據表單設定顯示的所有欄位

**特殊處理**：

- **複選框欄位**：每個選項會展開為獨立的列，已勾選的選項顯示「V」，未勾選的顯示空白
- **子群組欄位**：如果欄位屬於子群組，標題會顯示為「子群組名稱 - 欄位名稱」
- **下拉選單欄位**：會顯示選項的標籤文字而非值
- **供應商欄位**：會顯示供應商名稱而非代碼

### 4. 選項活頁簿

**功能說明**：管理表單下拉選單和複選框的選項資料。

**使用步驟**：

#### 4.1 新增活頁簿

1. 從首頁點擊「選項活頁簿」卡片，或從側邊欄選擇「選項活頁簿」
2. 點擊「新增活頁簿」按鈕
3. 填寫基本資訊：
   - **活頁簿鍵值**（必填）：活頁簿的唯一識別碼（會自動檢查重複）
   - **活頁簿名稱**（必填）：活頁簿的顯示名稱
   - **說明**：活頁簿的說明文字
   - **啟用狀態**：選擇是否啟用此活頁簿
4. 點擊「儲存」按鈕

#### 4.2 編輯活頁簿

1. 在活頁簿列表中，點擊「編輯」按鈕
2. 系統會開啟編輯對話框，包含兩個分頁：

   **定義儲存格**：
   - 定義活頁簿的欄位結構
   - **系統編號**（必填）：欄位的唯一識別碼（自動產生，格式：活頁簿鍵值_序號）
   - **儲存格名稱**（必填）：欄位的顯示名稱
   - **儲存格型態**（必填）：欄位的資料類型
   - **外部鍵值**：標記為鍵值欄位（用於選項的 value）
   - **外部標籤**：標記為標籤欄位（用於選項的 label）
   - 點擊「新增欄位」可新增欄位定義
   - 點擊「刪除」可刪除欄位

   **資料編輯**：
   - 使用 Excel 風格的編輯器編輯資料
   - 點擊「新增資料行」可新增資料列
   - 直接在儲存格中編輯資料
   - 點擊「儲存」按鈕儲存資料

3. 編輯完成後，點擊「儲存」按鈕

#### 4.3 在表單中使用選項活頁簿

1. 進入「表單管理」功能
2. 選擇要編輯的表單
3. 編輯欄位設定
4. 對於「下拉選單」或「多選下拉」類型的欄位：
   - 開啟「選項活頁簿」開關
   - 從下拉選單中選擇要使用的活頁簿
5. 儲存欄位設定

**注意事項**：

- 活頁簿必須啟用才能在表單中使用
- 活頁簿必須定義至少一個「外部鍵值」欄位和一個「外部標籤」欄位
- 刪除「外部鍵值」或「外部標籤」欄位時，系統會提示警告

### 5. 包裝說明設定

**功能說明**：設定產品包裝說明的模板和預設值。

**使用步驟**：

1. 從首頁點擊「包裝說明設定」卡片，或從側邊欄選擇「包裝說明設定」
2. 選擇產品分類（大類/中類/小類）

4. 點擊「儲存」按鈕儲存設定

### 6. 審核管理

**功能說明**：審核待審核的申請記錄。

**權限要求**：需要「審核人員」或「系統管理員」角色。

**使用步驟**：

1. 從首頁點擊「審核管理」卡片，或從側邊欄選擇「審核管理」
2. 系統會顯示待審核的申請列表
3. 點擊申請記錄查看詳細資訊
4. 在詳情對話框中：
   - 查看申請的完整資料
   - 查看審核流程和歷史記錄
5. 選擇審核動作：
   - **核准**：核准申請，進入下一層級審核或完成審核
   - **退回**：退回申請，申請人需要修改後重新提交
6. 填寫審核意見（可選）
7. 點擊「確認」按鈕完成審核

**審核狀態說明**：

- **待審核**：等待審核的申請
- **審核中**：正在審核流程中的申請
- **已核准**：已完成所有審核層級的申請
- **已退回**：被退回需要修改的申請
- **退回修改**：退回後重新提交的申請

**注意事項**：

- 審核管理頁面會顯示待審核申請的數量徽章
- 審核意見會記錄在審核歷史中
- 退回的申請可以查看退回原因

### 7. 表單管理

**功能說明**：管理動態表單的結構和欄位定義。

**權限要求**：需要「系統管理員」角色。

**使用步驟**：

#### 7.1 新增表單

1. 從首頁點擊「表單管理」卡片，或從側邊欄選擇「表單管理」
2. 點擊「新增表單」按鈕
3. 填寫表單基本資訊：
   - **表單代碼**：表單的唯一識別碼
   - **表單名稱**：表單的顯示名稱
   - **表單名稱（英文）**：表單的英文名稱
   - **說明**：表單的說明文字
   - **啟用狀態**：選擇是否啟用此表單
4. 點擊「儲存」按鈕

#### 7.2 編輯表單欄位

1. 在表單列表中，點擊「編輯」按鈕
2. 系統會開啟表單設計器，包含兩個區域：

   **左側：欄位列表**
   - 顯示表單的所有欄位
   - 可以拖曳調整欄位順序
   - 點擊欄位可編輯欄位設定

   **右側：表單預覽**
   - 即時預覽表單的顯示效果
   - 可以測試表單的互動功能

3. **新增欄位**：
   - 點擊「新增欄位」按鈕
   - 選擇欄位類型
   - 填寫欄位設定：
     - **欄位鍵值**：欄位的唯一識別碼
     - **欄位標籤**：欄位的顯示名稱
     - **欄位類型**：選擇欄位類型
     - **是否必填**：設定是否為必填欄位
     - **欄位群組**：設定欄位所屬的群組
     - **子群組**：設定欄位所屬的子群組
     - **顯示順序**：設定欄位的顯示順序
     - **選項設定**：對於需要選項的欄位類型，設定選項列表
     - **選項活頁簿**：可選擇使用選項活頁簿作為選項來源
   - 點擊「儲存」按鈕

4. **編輯欄位**：
   - 點擊欄位列表中的欄位
   - 修改欄位設定
   - 點擊「儲存」按鈕

5. **刪除欄位**：
   - 點擊欄位列表中的「刪除」按鈕
   - 確認刪除

**欄位類型說明**：

- **文字**：單行文字輸入框
- **多行文字**：多行文字輸入框
- **數字**：數字輸入框
- **下拉選單**：單選下拉選單
- **多選下拉**：多選下拉選單
- **複選框**：複選框（每個選項會展開為獨立列）
- **單選框**：單選框
- **日期**：日期選擇器
- **日期時間**：日期時間選擇器
- **檔案上傳**：檔案上傳欄位
- **JSON 資料**：JSON 格式資料輸入
- **階層選單**：多層級階層選單
- **自動產生**：自動產生欄位（如料號）

**注意事項**：

- 表單必須至少定義一個欄位
- 欄位鍵值必須唯一
- 修改表單結構會影響現有的申請資料，請謹慎操作

### 8. 審核流程設定

**功能說明**：設定申請的審核流程和審核層級。

**權限要求**：需要「系統管理員」角色。

**使用步驟**：

1. 從首頁點擊「審核流程設定」卡片，或從側邊欄選擇「審核流程設定」
2. 選擇要設定的表單
3. 設定審核流程：
   - **審核層級**：設定審核的層級數量
   - **審核人員**：為每個層級指定審核人員或角色
   - **審核條件**：設定審核通過的條件
4. 點擊「儲存」按鈕

**注意事項**：

- 審核流程設定會影響新提交的申請
- 修改審核流程不會影響正在審核中的申請

---

### 9. 使用者管理

**功能說明**：管理系統使用者、角色和權限。

**權限要求**：需要「系統管理員」角色。

**使用步驟**：

#### 9.1 使用者管理

1. 從首頁點擊「使用者管理」卡片，或從側邊欄選擇「使用者管理」
2. 選擇「使用者」分頁
3. **新增使用者**：
   - 點擊「新增使用者」按鈕
   - 填寫使用者資訊：
     - **使用者名稱**：登入使用的使用者名稱
     - **Email**：使用者的電子郵件
     - **姓名**：使用者的真實姓名
     - **角色**：選擇使用者的角色
     - **部門**：選擇使用者所屬的部門
     - **狀態**：選擇是否啟用此帳號
   - 點擊「儲存」按鈕

4. **編輯使用者**：
   - 在使用者列表中，點擊「編輯」按鈕
   - 修改使用者資訊
   - 點擊「儲存」按鈕

5. **刪除使用者**：
   - 在使用者列表中，點擊「刪除」按鈕
   - 確認刪除

6. **搜尋和篩選**：
   - 使用搜尋框搜尋使用者（姓名、Email）
   - 使用角色下拉選單篩選角色
   - 使用狀態下拉選單篩選狀態

#### 9.2 角色權限管理

1. 選擇「角色權限」分頁
2. **新增角色**：
   - 點擊「新增角色」按鈕
   - 填寫角色資訊：
     - **角色代碼**：角色的唯一識別碼（只能包含小寫字母、數字和底線）
     - **角色名稱**：角色的顯示名稱
     - **角色名稱（英文）**：角色的英文名稱
     - **說明**：角色的說明文字
     - **顯示順序**：角色的顯示順序
     - **啟用狀態**：選擇是否啟用此角色
   - 選擇「頁面權限」分頁，設定角色可以訪問的頁面：
     - 勾選允許訪問的頁面
     - 頁面會按照指定順序排列，單數在左邊，雙數在右邊
   - 點擊「儲存」按鈕

3. **編輯角色**：
   - 在角色列表中，點擊「編輯」按鈕
   - 修改角色資訊和頁面權限
   - 點擊「儲存」按鈕

4. **分配權限**：
   - 在角色列表中，點擊「分配權限」按鈕（鑰匙圖示）
   - 勾選要分配給角色的權限
   - 點擊「儲存」按鈕

5. **刪除角色**：
   - 在角色列表中，點擊「刪除」按鈕
   - 確認刪除（系統內建角色無法刪除）

**角色說明**：

- **系統管理員（admin）**：擁有所有功能的完整權限
- **審核人員（approver）**：可以審核申請、查詢申請記錄
- **申請人員（applicant）**：可以提交申請、查詢自己的申請記錄

**頁面權限說明**：

頁面權限控制角色可以訪問哪些功能頁面。頁面會按照以下順序排列：

1. 物料申請
2. 申請查詢
3. EXCEL匯出
4. 選項活頁簿
5. 包裝說明設定
6. 審核管理
7. 表單管理
8. 審核流程設定
9. 使用者管理
10. 系統設定

#### 9.3 部門管理

1. 選擇「部門管理」分頁
2. **新增部門**：
   - 點擊「新增部門」按鈕
   - 填寫部門資訊：
     - **部門代碼**：部門的唯一識別碼
     - **部門名稱**：部門的顯示名稱
     - **上級部門**：選擇上級部門（可選）
     - **部門主管**：選擇部門主管（可選）
     - **說明**：部門的說明文字
   - 點擊「儲存」按鈕

3. **編輯部門**：
   - 在部門列表中，點擊「編輯」按鈕
   - 修改部門資訊
   - 點擊「儲存」按鈕

4. **刪除部門**：
   - 在部門列表中，點擊「刪除」按鈕
   - 確認刪除

**注意事項**：

- 刪除使用者前，請確認該使用者沒有未完成的申請記錄
- 刪除角色前，請確認沒有使用者使用此角色
- 系統內建角色（admin、approver、applicant）無法刪除

## 常見問題

### Q1: 如何修改密碼？

A: 目前系統不支援使用者自行修改密碼，如需修改密碼請聯繫系統管理員。

### Q2: 為什麼我看不到某些功能？

A: 功能的可見性由您的角色權限決定。如果您看不到某些功能，可能是因為：
- 您的角色沒有該功能的訪問權限
- 該功能已被系統管理員停用
- 請聯繫系統管理員確認您的權限設定

### Q3: 申請提交後可以修改嗎？

A: 申請提交後無法直接修改。如果申請被退回，您可以：
- 查看退回原因
- 根據退回意見修改資料
- 重新提交申請

### Q4: 如何查看申請的審核進度？

A: 您可以：
- 在「申請查詢」功能中查詢您的申請記錄
- 點擊申請記錄查看詳細資訊
- 在詳情中查看審核歷史記錄

### Q5: Excel 匯出的檔案格式是什麼？

A: 系統匯出的是 CSV 格式的檔案，可以用 Excel、Google Sheets 等軟體開啟。

### Q6: 複選框欄位在 Excel 匯出中如何顯示？

A: 複選框欄位的每個選項會展開為獨立的列，已勾選的選項顯示「V」，未勾選的顯示空白。

### Q7: 如何設定表單的預設值？

A: 在「表單管理」功能中編輯欄位時，可以設定欄位的預設值。

### Q8: 選項活頁簿和手動設定選項有什麼差別？

A: 
- **選項活頁簿**：集中管理選項資料，可以在多個表單中重複使用，資料更新時所有使用該活頁簿的表單都會自動更新
- **手動設定選項**：選項直接設定在欄位中，只適用於該欄位

### Q9: 如何知道哪些申請需要我審核？

A: 在「審核管理」功能中，系統會顯示所有待審核的申請。頁面標題旁會顯示待審核申請的數量徽章。

### Q10: 系統支援哪些瀏覽器？

A: 系統支援以下瀏覽器：
- Chrome 90+
- Edge 90+
- Firefox 88+
- Safari 14+

建議使用最新版本的瀏覽器以獲得最佳體驗。

## 注意事項

### 資料安全

- 請妥善保管您的帳號密碼，不要與他人分享
- 登出時請記得點擊「登出」按鈕，不要直接關閉瀏覽器
- 在公共電腦使用後，請務必登出

### 資料備份

- 系統會自動備份資料，但建議重要資料請自行備份
- Excel 匯出功能可以用於備份申請資料

### 瀏覽器相容性

- 建議使用最新版本的瀏覽器
- 如果遇到顯示問題，請嘗試清除瀏覽器快取
- 建議啟用 JavaScript 功能

### 網路連線

- 系統需要穩定的網路連線
- 如果網路不穩定，可能會影響資料載入和儲存
- 建議在穩定的網路環境下使用系統

### 資料輸入

- 請仔細檢查輸入的資料，確認無誤後再提交
- 必填欄位必須填寫，否則無法提交
- 日期格式請按照系統提示的格式輸入

### 權限管理

- 只有系統管理員可以管理使用者、角色和權限
- 權限變更會立即生效，請謹慎操作
- 刪除使用者或角色前，請確認沒有相關的資料關聯

### 系統維護

- 系統維護期間可能無法使用，請留意系統公告
- 維護期間請勿進行重要操作，以免資料遺失
